# 공공데이터 출처별 검색 요령

> 주소·메뉴는 바뀔 수 있다. 아래는 검색 질의를 만들기 위한 출발점이며, 실제 링크는 매번 웹검색·페이지 확인으로 검증한다.

| 출처 | 주소 | 잘 맞는 데이터 | 검색 질의 예 | 받는 방법 |
|---|---|---|---|---|
| 공공데이터포털 | data.go.kr | 중앙부처·공공기관 파일/Open API, 표준데이터 | `site:data.go.kr <주제> 표준데이터`, `site:data.go.kr <주제> 파일데이터` | 파일: 상세 페이지 다운로드 / Open API: 활용신청 → 인증키(serviceKey) |
| 국가통계포털 KOSIS | kosis.kr | 집계 통계(시도·시군구·연도) | `site:kosis.kr <통계명>` | 통계표 다운로드(CSV/XLSX), 공유서비스 Open API(별도 키) |
| 서울 열린데이터광장 | data.seoul.go.kr | 서울시 실시간·행정 데이터 | `site:data.seoul.go.kr <주제>` | 파일·Open API(별도 키) |
| 경기데이터드림 | data.gg.go.kr | 경기도 데이터 | `site:data.gg.go.kr <주제>` | 파일·Open API |
| 지방행정 인허가 데이터 | localdata.go.kr | 업종별 인허가 사업장(음식점·병원 등) | `지방행정 인허가 데이터 <업종>` | 전체/변동분 파일 |
| 한국은행 ECOS | ecos.bok.kr | 금리·물가·국민계정 | `ECOS <지표명>` | Open API(별도 키) |
| 전자공시 OpenDART | opendart.fss.or.kr | 기업 공시·재무 | `OpenDART <항목>` | Open API(별도 키) |
| 공공데이터 지도(국토) | vworld.kr | 공간·주소·지적 | `브이월드 <데이터>` | 파일·API |

## 규모 가늠
- 상세 페이지의 "전체 행 수/파일 크기"를 먼저 본다. 없으면 샘플 다운로드 후 `ingest plan` 결과의 `rows_estimated` 로 판단.
- 로그성(시각 컬럼 + 계속 쌓이는 데이터: 교통량·센서·접속 기록)은 건수가 적어도 레이크 저장을 제안할 수 있다.

## 라이선스 표기
- 공공누리 제1유형(출처표시)~제4유형(출처표시+상업적 이용금지+변경금지)을 그대로 적는다.
- "이용허락범위 제한 없음"이라도 출처 표기는 남긴다.
