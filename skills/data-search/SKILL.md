# 공공데이터 검색 (data-search)

목적: 사용자의 검색어로 **실제로 내려받을 수 있는 데이터의 정확한 링크**를 찾아 주고, 원하면 그대로 저장까지 잇는다. 추측한 링크를 주지 않는다 — 검색 결과에서 확인한 페이지만 쓴다.

## 흐름

```
검색어 → (1) 의도 정리 → (2) 웹검색·페이지 확인 → (3) 결과 표 → [사용자 선택] "저장해"
      → (4) 규모 판정(DB / 레이크) → data-ingest 로 인계
```

### 1. 의도 정리 (묻지 말고 추론, 모호하면 한 번만 확인)
- 주제·지역·기간·단위(시도/시군구/사업장)·갱신 주기 필요 여부.
- 동의어를 2~3개 만든다(예: "어린이집" → 보육시설, 어린이집 표준데이터, 보육통계).

### 2. 검색 — WebSearch/WebFetch 로 확인
- `references/sources.md`의 포털별 검색 요령으로 질의를 만든다. 예: `site:data.go.kr 어린이집 표준데이터`, `site:kosis.kr 보육 시설 수`.
- 후보 페이지를 열어(WebFetch) **데이터명·제공기관·형식(CSV/XLSX/JSON/Open API)·갱신일·건수·라이선스·다운로드/API URL**을 확인한다. 확인 못 한 칸은 "확인 필요"로 비워 둔다.
- 같은 데이터가 여러 곳에 있으면 **원 제공기관 > 공공데이터포털 > 기타 미러** 순으로 고른다.

### 3. 결과 표 (최대 8개, 관련도순)

| # | 데이터명 | 제공기관 | 형식 | 갱신 | 규모(추정) | 라이선스 | 링크 |
|---|---|---|---|---|---|---|---|
| 1 | 전국어린이집표준데이터 | 한국사회보장정보원 | CSV·API | 분기 | 약 3만 행 | 이용허락범위 제한 없음 | [데이터 페이지](…) |

표 아래에 짧게: 추천 1~2개와 이유, API 키가 필요한 항목(공공데이터포털 Open API 는 **활용신청 후 인증키** 필요), 개인정보 가능성이 있는 데이터(예: 대표자명 포함) 표시.

### 4. "저장해" → data-ingest 인계
1. 규모 판정: 건수·파일 크기가 크거나(기본 1천만 행 / 2GB 이상) 시각 컬럼이 있는 append-only 로그성이면 **레이크(Parquet + DuckDB) 저장을 제안**하고 이유를 말한다. 사용자가 DB 를 원하면 파티션 테이블 대안을 함께 안내한다. 판정 기준은 설정 `ingest.large_rows`·`large_bytes`.
2. 파일 데이터: 다운로드 URL 을 그대로 넘긴다.
   ```bash
   PYTHONPATH=$RT python -m dataplatform --config $CFG ingest plan "<다운로드 URL>" --type PUBLIC --name "<데이터명>" --provider "<제공기관>" --license "<라이선스>" --schema pub
   ```
   다운로드 URL 이 페이지 안 버튼(자바스크립트)뿐이라 직접 받을 수 없으면, 사용자에게 받아서 연결 폴더에 넣어 달라고 하고 그 파일 경로로 진행한다.
3. Open API(JSON): 인증키가 설정(`public_data.service_key`)에 있어야 한다.
   ```bash
   PYTHONPATH=$RT python -m dataplatform --config $CFG public-api "<API URL>" --param key=value --out work/xxx.json
   PYTHONPATH=$RT python -m dataplatform --config $CFG ingest plan work/xxx.json --type PUBLIC --name "<데이터명>" --provider "<기관>"
   ```
4. 이후 단계(테이블 이름·단어 등록·개인정보·승인·적재)는 **data-ingest 스킬**을 따른다.

`$RT` = 플러그인 루트의 `runtime` 폴더(이 스킬 폴더 기준 `../../runtime`), `$CFG` = 시스템 설정 파일(system.yaml).

## 원칙
- 링크는 확인한 것만. 페이지가 열리지 않으면 표에 "접속 실패"라고 쓰고 대안을 찾는다.
- 데이터 라이선스(공공누리 유형 등)와 출처 표기 의무를 표에 남긴다 — 적재할 때 `ingest.source.license_nm`에 기록된다.
- 개인정보가 포함될 수 있는 데이터는 적재 시 자동으로 `pi` 스키마에 암호화되어 분리된다는 점을 알린다.
